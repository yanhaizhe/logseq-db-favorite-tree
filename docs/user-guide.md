# 使用指南

本文档面向插件使用者，说明 `Logseq DB Favorite Tree` 的安装方式、基础概念、常用操作、设置项含义与常见问题。

## 1. 适用范围

- 适用于 `Logseq DB graph`
- 不适用于 `file graph`
- 页面层级关系来自页面属性，默认使用 **`Page Tags`**（中文界面显示为 **`页面标签`**）

## 2. 安装方式

### 2.1 本地开发加载

1. 在项目目录执行安装依赖：

```bash
npm install
```

2. 执行构建：

```bash
npm run build
```

3. 在 Logseq 中开启开发者模式
4. 选择 `Load unpacked plugin`
5. 选择当前项目目录完成加载

## 3. 基础概念

### 3.1 根节点

- 插件会把 Logseq 收藏页作为树的根节点
- 只有被收藏的页面才会出现在第一层

### 3.2 子节点

- 子节点来自页面属性关系
- 默认读取 **`Page Tags`**（`页面标签`）属性，并全面支持别名兼容（`page-tags`、`tags`、`parent`）
- 如果某页面声明其父页面为某个收藏页或某个树中页面，它就会作为对应子节点出现

### 3.3 当前页实时跟随与定位

- **实时高亮跟随**：无论是在目录树内点击跳转，还是在 Logseq 主窗口打开页面，目录树会自动感知并高亮显示「当前页」
- **路径自动展开**：若当前页属于收藏树的某个深层分支，插件会自动展开其所有父级分支，确保当前活动页立即可见
- **一键手动定位**：点击“定位当前页”可快速聚焦并短暂高亮页面所在节点

## 4. 从零设置页面层级（`Page Tags` / `页面标签`）

这一节面向第一次使用属性组织页面层级的用户，目标是让一张页面出现在另一张页面下面。

### 4.1 理解 Logseq DB 中的父子关系

- 假设你希望 `子页面A` 出现在 `父页面B` 下面
- 在 Logseq DB 中，只需为 `子页面A` 设置 **`Page Tags`**（中文界面显示为 **`页面标签`**），其值选择或填写为 `父页面B`
- 插件读取后，就会把 `子页面A` 挂到 `父页面B` 下面展示

可以理解为：

```text
子页面A
页面标签 (Page Tags) -> 父页面B
```

### 4.2 方式一：使用插件的「新建子页面」全自动完成（推荐 ⭐）

无需手动编辑属性，插件提供了 100% 全自动化的方式：
1. 在目录树中右键点击任意父节点（如 `项目管理`），或悬停点击右侧的 `···` 更多操作按钮；
2. 点击 **「新建子页面」**；
3. 输入子页面标题并按下 `Enter` 提交；
4. 插件将自动创建页面、原子化绑定 `Page Tags` 实体关系、自动展开父级并在树中定位高亮新页面。页面干干净净，无任何多余的空白块。

### 4.3 方式二：在页面属性中手动设置

如果你希望将现有页面挂载到某个父节点下：
1. 打开子页面（例如 `周计划`）；
2. 在页面顶部的属性区域点击 **「+ 添加属性」**；
3. 在属性列表中选择 **`Page Tags`**（若 Logseq 设为中文，也可直接搜索 `页面标签`）；
4. 在属性值中选择上级父页面（例如 `项目管理`）；
5. 保存后，`周计划` 即刻自动出现在 `项目管理` 节点下方。

说明：
- 插件支持多值父页面：如果一个页面属于多个上级，可在 `Page Tags` 中添加多个父页面，该页面会同时出现在多条分支下；
- 兼容旧属性名：如果你的图谱此前习惯使用 `parent` 或 `tags`，插件内置了智能别名映射，无需额外修改也能平滑识别。
```text
页面：周计划
页面标签 (Page Tags)：[[项目管理]]
```

这适合最常见的一对一层级关系。

### 4.4 设置多值父页面

如果一个页面希望同时挂到多个父页面下面：
1. 打开目标子页面，例如 `会议纪要`；
2. 在 `Page Tags`（或 `页面标签`）属性中依次添加多个父页面（例如 `项目管理` 和 `团队协作`）；
3. 插件会自动把该页面挂到所有相关父页面分支下，且在使用“定位当前页”时会同时展开所有相关路径。

示例：

```text
页面：会议纪要
页面标签 (Page Tags)：[[项目管理]], [[团队协作]]
```

### 4.5 属性别名与格式兼容

插件针对 Logseq DB 进行了全方位的属性别名兼容与解析适配：
- **属性名支持**：优先匹配 `Page Tags` 与 `页面标签`，同时智能兼容 `page-tags`、`parent`、`tags`；
- **格式支持**：支持 Logseq DB 原生实体引用对象（Entity ID）、数组多值、以及正文属性块语法（如 `tags:: [[xxx]]`、`parent:: [[xxx]]`）。

### 4.6 验证结果

1. 确保父页面已加入 Logseq 收藏（作为一级根节点入口）；
2. 打开插件面板或侧边栏；
3. 展开父页面，即可看到新建或关联的子页面；
4. 插件具备 200ms 内的智能实时数据同步，通常无需手动刷新。

## 5. 快速上手

### 5.1 打开插件

- 在 Logseq 顶部工具栏点击插件图标
- 插件会根据当前模式显示为原生侧边栏、悬浮面板或悬浮球入口

### 5.2 显示模式

- `sidebar`：仅在 Logseq 原生左侧边栏展示树
- `floating`：仅使用悬浮面板与悬浮球
- `mixed`：允许在原生侧边栏与悬浮面板之间切换
- 默认预设为 `sidebar`
- `mixed` 模式初始化时也会优先展示侧边栏

### 5.3 浏览树结构

- 点击节点左侧展开按钮查看下级内容
- 点击页面标题可直接打开对应页面
- **实时活动页高亮与自动展开**：无论通过点击树节点，还是在 Logseq 内部跳转（搜索、双链跳转等触发路由变更），插件均会自动高亮当前活动页面，并自动展开其所在的祖先路径
- 没有子页面的节点不会显示展开标识

### 5.4 定位当前页

- 点击工具栏中的定位按钮
- 插件会自动展开当前页所在的所有路径
- 目标节点会出现定位标记并短暂高亮

### 5.5 搜索页面

- 在搜索框输入页面标题关键字
- 插件仅展示命中页面及其祖先路径
- 搜索结果支持关键词高亮
- 搜索状态下仍可手动折叠 / 展开结果树
- 清空搜索框后恢复完整树视图

### 5.6 更多操作与右键菜单（上下文菜单）

在目录树中，你可以通过两种方式唤出上下文功能菜单：
1. **鼠标右键**点击任意树节点；
2. 鼠标悬停在节点上，点击右侧出现的 **`···`**（更多操作）按钮。

菜单会**跟随鼠标光标点击点**精准弹出，并具备视口边界智能检测，防止超出屏幕。

菜单包含 7 项实用能力：
- **在右侧边栏打开**：在 Logseq 右侧辅助侧边栏分屏打开该页面，便于双屏对照编辑；
- **新建子页面**：弹出内联输入框，输入标题回车即可全自动创建子页面并完成 `Page Tags` 实体关联，新页面纯净无空白占位块；
- **复制页面引用**：将 `[[页面标题]]` 复制到剪贴板。内置 5 层容灾机制（含 Electron 原生及宿主中转），稳定应对各类沙盒与失焦环境；
- **复制页面名称**：将纯文本页面标题复制到剪贴板；
- **展开所有子级**：一键递归展开当前节点下的所有下级页面；
- **折叠所有子级**：一键递归收起当前节点下的所有下级页面；
- **恢复默认排序**：如果当前层级此前进行过手动拖拽重排，可一键清空自定义排序并还原默认标题顺序。

## 6. 面板操作

### 6.1 拖动面板

- 按住标题栏拖动可改变面板位置
- 拖动结果会被记住

### 6.2 调整面板大小

- 拖动右下角可调整宽高
- 点击“默认尺寸”可恢复默认大小

### 6.3 收回悬浮球

- 点击面板收回按钮，或双击标题栏
- 面板会收回为一个悬浮球
- 点击悬浮球可再次展开面板

### 6.4 悬浮球拖动

- 悬浮球可自由拖动
- 拖动结束后会自动吸附到左侧或右侧边缘

## 7. 工具区说明

### 7.1 功能区收起

- 顶部功能区支持一键收起 / 展开
- 收起后可为树内容腾出更多空间

### 7.2 说明提示

- 标题栏左上角的 `i` 图标用于显示说明
- 鼠标停留或点击后可查看当前提示信息

### 7.3 实时事件驱动与刷新控制

- **智能事件驱动实时同步**：插件自动监听图谱数据库变动（`logseq.DB.onChanged`）。当你添加页面标签值、移除页面标签值、修改页面标签或父级属性（如 `parent`、`tags`）时，目录树会在 200ms 内自动精准刷新，无需手动点击。
- **正文编辑打字零打扰**：插件内置智能过滤引擎，在页面正文中日常打字、敲击回车换行形成新块、缩进移动块时，均被精准识别为常规编辑排版而**绝不会触发目录树刷新**，保障写作沉浸感。
- **无感平滑置换**：数据刷新采用双缓冲机制与 Datascript 批量查询，全图建索引仅需约 20ms，刷新过程不白屏、不闪烁，并自动保留当前已展开分支与滚动位置。
- **支持手动刷新**：可在工具栏或面板工具区随时点击刷新按钮强制重新拉取。
- **自动轮询（兜底）**：自动轮询刷新默认关闭；开启后按设定间隔（默认 `60` 秒）定时校验。
- **语言切换自动同步**：当 Logseq 应用语言切换后，面板文案会自动刷新并跟随新语言显示。

### 7.4 侧边栏模式补充

- 原生侧边栏模式下同样支持搜索、定位、展开全部 / 折叠全部、刷新和设置
- 固定为 `sidebar` 或 `floating` 时，不显示模式切换按钮

## 8. 排序说明

### 8.1 默认排序

- 根节点默认按页面标题排序
- 子节点默认按页面标题排序

### 8.2 自定义排序

- 可以拖动节点左侧的排序把手
- 仅支持同级节点之间重排
- 自定义排序会覆盖当前层的默认顺序
- 排序结果会按 graph 独立记住

### 8.3 搜索中的限制

- 搜索状态下不能拖拽排序
- 这是为了避免筛选结果与真实树顺序混淆

## 9. 设置项说明

### 9.1 层级属性名

- 默认值为 `Page Tags`（页面标签）
- 用于声明“当前页面的父页面是谁”
- 插件内置智能别名映射，如果图谱此前习惯使用 `parent`、`tags` 或 `page-tags`，均可被自动识别，通常无需额外修改
- 如果你的图谱使用自定义属性名来组织层级，可在这里改成对应字段

### 9.2 面板宽度

- 控制面板默认宽度
- 用户手动缩放后的尺寸会另外记住

### 9.3 自动刷新间隔（秒）

- 控制轮询自动刷新的时间间隔
- 数值越小，树刷新越及时，但轮询频率也越高
- 默认值为 `60`
- 自动刷新默认处于关闭状态，需要在面板中手动开启

### 9.4 初始侧向偏好

- 控制首次显示时默认靠左还是靠右
- 如果你已经拖动过面板或悬浮球，插件会优先使用最近记住的位置

### 9.5 显示模式预设

- 可选 `sidebar`、`floating`、`mixed`
- `sidebar` 为仅原生侧边栏
- `floating` 为仅悬浮模式
- `mixed` 为两者可切换

## 10. graph 级状态记忆

插件会为不同 graph 分别记住以下状态：

- 面板位置
- 面板尺寸
- 悬浮球位置
- 展开状态
- 功能区收起状态
- 排序结果
- 显示模式与视图模式
- 最近定位节点

这意味着你切换到另一个 graph 时，会看到该 graph 自己的树状态，而不是共用上一张图谱的布局和排序。

## 11. 常见问题

### 11.1 为什么页面没有出现在树里？

常见原因包括：

- 页面没有被加入收藏，因此不会成为根节点
- 页面虽然存在，但没有通过 `Page Tags`（或别名 `parent`、`tags`）挂到某个已显示节点上
- 当前使用的层级属性名被自定义修改过，与页面实际属性不一致

### 11.2 为什么定位不到当前页？

常见原因包括：

- 当前页面不在收藏树覆盖范围内
- 当前页面没有通过层级关系连接到任何收藏根节点
- 页面标题与属性引用不一致，导致关系未被正确识别

### 11.3 为什么搜索时不能拖拽排序？

- 搜索结果只展示部分路径，并不是完整同级结构
- 为避免误操作，插件在搜索态禁用了拖拽排序

### 11.4 为什么切换 graph 后状态变了？

- 这是预期行为
- 插件会按 graph 分别记住布局、排序与展开状态

### 11.5 `Page Tags` / 父属性应该填纯文本还是页面引用？

- 必须/推荐填写页面引用或实体对象
- 最稳妥的方式是在属性面板中选择页面对象，或在树节点右键使用 **「新建子页面」** 自动绑定
- 文本引用可写为 `[[页面名]]`

### 11.6 一个页面可以设置多个父页面吗？

- 可以
- 只要在 `Page Tags`（或 `parent`）中添加多个父页面引用，插件就会把它挂载到多条路径中

### 11.7 在正文打字或敲回车换行会触发目录树刷新吗？

- **不会**。插件内置深度的底层事务过滤器，常规的文字输入、敲击回车换行生成新块（`split-block`）、Tab 缩进与块位置移动均被智能屏蔽，绝不打断打字流。
- 只有当你修改了页面级标签（`:block/tags`）、配置的层级属性（如 `Page Tags`、`parent`），或者在块中输入了 `tags:: [[xxx]]` / `parent:: [[xxx]]` 等显式属性语法时，插件才会触发实时精准刷新。

## 12. 推荐使用习惯

- **善用右键「新建子页面」**：直接在目标父节点上右键新建，不仅省去手动打标签的繁琐，还保证页面干净无空白占位块。
- **用收藏夹维护根导航，用页面标签维护层级**：将核心项目、知识库主题页加入收藏，子任务与细分笔记通过 `Page Tags` 组织。
- **需要对照参考时使用分屏**：右键点击树节点并选择“在右侧边栏打开”，无需切走当前阅读视图。
- **多端与大屏适配**：常用阅读推荐原生侧边栏（`sidebar` 模式）；宽屏多任务可随时切为悬浮面板或悬浮球。
