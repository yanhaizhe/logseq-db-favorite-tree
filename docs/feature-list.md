# 功能清单

本文档用于汇总 `Logseq DB Favorite Tree` 当前已实现能力、交互边界与建议中的下一步迭代方向，便于后续排期、验收与沟通。

## 1. 产品目标

- 将 Logseq 收藏页转化为可持续维护的层级导航树
- 让页面组织结构依赖页面属性而非手工目录
- 提供轻量、常驻、低打扰的悬浮导航入口
- 在不同 graph 下分别保留各自的使用上下文

## 2. 当前已实现功能

### 2.1 根节点与关系解析

- 以 Logseq 收藏页作为树根节点来源
- 通过页面属性关系构建树层级，默认属性名为 **`Page Tags`**（在中文界面对应显示为 **`页面标签`**）
- 深度适配 Logseq DB 原生属性体系，支持双向别名自动兼容映射（`Page Tags` ↔ `页面标签` ↔ `page-tags` ↔ `tags` ↔ `parent`）
- 支持节点属性、多值属性、页面引用对象（`node` 类型实体 ID 数组 `[parentId]`）等多种属性值结构
- 对 DB 内部属性键格式做兼容匹配，支持 Clojure 属性关键字（如 `:logseq.property/page-tags`、`:user.property/Page Tags`）
- 支持 Datascript 批量查询，单次拉取全图页面与标签实体，全树索引构建耗时由 10~30s 缩减至约 20ms（500+ 倍提速）
- 提供高并发分块拉取兜底机制（`BATCH_SIZE = 25`），在不支持 Datascript 的环境下平滑兼容
- 支持循环依赖检测，避免树递归进入死循环

### 2.2 树浏览与定位

- 根节点默认按页面标题排序
- 子节点默认按页面标题排序
- 支持展开单个节点并懒加载子节点
- 支持一键展开全部 / 折叠全部
- **当前页实时跟随高亮**：无论在树内点击跳转页面，还是在 Logseq 主界面切换路由，左侧栏目录树即时感知并高亮显示当前页面
- **当前页路径自动展开**：识别到当前活动页面位于收藏树分支时，自动以 `merge` 模式展开其所有父级分支，确保当前活动页始终清晰可见
- 支持一键定位当前页，并展开所有命中的相关路径（不只展开第一条）
- 定位节点会显示定位标记并短暂高亮
- 当用户切换到其他页面后，旧的定位标记会自动清除
- 顶部显示当前页面在树中的面包屑路径，并支持点击跳转
- 支持「聚焦当前路径」：仅保留当前页路径展开，收起其余所有分支
- 支持「折叠其他分支」：收起当前页路径之外的所有分支
- 搜索状态下展开全部 / 折叠全部作用于可见命中结果，而非全树

### 2.3 搜索与筛选

- 支持树内搜索
- 搜索结果保留命中节点及其祖先路径
- 搜索状态下隐藏无关分支，减少视觉噪音
- 搜索结果支持关键词高亮
- 搜索状态下支持手动折叠 / 展开结果树
- 搜索时禁用拖拽排序，避免筛选态与真实层级顺序混淆
- 支持搜索多命中「上一条 / 下一条」切换导航，当前命中位置显示为 N/M
- 切换命中项后自动滚动到对应节点

### 2.4 显示模式与界面形态

- 支持 `sidebar`、`floating`、`mixed` 三种显示模式
- 默认显示模式预设为 `sidebar`
- `mixed` 模式下初始化优先展示侧边栏
- 固定 `sidebar` 或 `floating` 时隐藏模式切换按钮
- 原生侧边栏与悬浮 UI 互斥显示，避免重复渲染
- 支持从侧边栏切回悬浮面板，也支持从悬浮面板切到原生侧边栏

### 2.5 排序与自定义顺序

- 树目录默认使用标题排序作为基础顺序
- 支持同级节点拖拽自定义排序
- 自定义排序建立在默认排序之上，新节点仍能获得合理默认位置
- 根节点排序和子节点排序均支持自定义覆盖
- 排序状态按 graph 维度独立持久化
- 支持在「默认排序」与「自定义排序」之间切换，切到默认排序时保留已保存的自定义顺序
- 支持「清除自定义排序」（含二次确认弹窗），彻底删除当前层已保存的自定义顺序
- 当前层处于自定义排序时提供视觉状态标记

### 2.6 面板与悬浮交互

- 支持工具栏图标打开 / 关闭面板
- 面板支持自由拖动
- 面板右下角支持拖拽缩放
- 面板支持一键恢复默认尺寸
- 面板标题栏支持双击收回为悬浮球
- 收回后可通过悬浮球再次展开面板
- 悬浮球支持自由拖动
- 悬浮球拖拽结束后自动吸附到左右边缘
- 面板初始位置支持左 / 右侧偏好
- 拖动后优先使用用户最近一次位置

### 2.7 面板内容区与工具区

- 面板功能区支持一键收起 / 展开
- 功能区收起后为树内容腾出更多可视空间
- 标题栏左上角说明文本已收进 `i` 图标提示中
- `i` 图标支持悬停或点击后查看说明
- 标题栏提示区域与拖拽区域做了事件隔离，避免误拖拽
- 原生侧边栏模式保留搜索、定位、展开全部 / 折叠全部、刷新与设置
- 面板与侧边栏按钮图标已做更强语义化区分
- 常用按钮支持 tooltip 瞬时提示
- 面板主体、工具条与包屑区域使用轻量滚动条样式

### 2.8 刷新与状态恢复

- 支持智能事件驱动实时刷新：深度过滤 `logseq.DB.onChanged` 事务，普通打字、回车换行分块（`split-block`）、缩进移动等常规编辑绝不触发刷新，写作过程零打扰
- 精准识别标签与属性变动：仅在添加、移除、修改页面标签值（`tags`、`page tags`、`:block/tags`）或层级属性值（`parent`）时触发实时刷新
- 支持文本属性语法变更识别：在块中输入或修改 `tags:: [[xxx]]`、`parent:: [[xxx]]` 时精准响应
- 变更防抖（200ms）与并发追发机制（`pendingRefreshReason`），确保高频编辑下不错过任何一次属性修改
- 双缓冲原子替换刷新：在内存后台完成索引计算后无感替换，刷新过程不白屏、不闪烁，无损保留节点展开状态与滚动位置
- 支持手动刷新与轮询自动刷新（默认关闭，可自定义间隔）
- 记住展开状态、滚动位置、上次定位节点
- 不同 graph 独立记住面板位置、尺寸、悬浮球位置、展开状态、功能区状态、排序、显示模式与视图模式

### 2.9 主题与兼容性

- 自动跟随 Logseq 明暗主题
- 面向 DB graph 使用场景
- 已声明不支持 file graph
- 对旧版或差异化返回结构做尽量归一化处理

### 2.10 节点快捷操作与右键上下文菜单

- **右键与更多操作上下文菜单（Context Menu）**：
  - 支持右键点击树节点或点击节点行悬浮的 `···` 操作按钮弹出菜单；
  - 菜单位置自适应跟随点击坐标，内置视口边界溢出保护；
  - 包含 7 项核心快捷操作：
    1. **在右侧栏打开**：一键将页面打开至 Logseq 原生右侧边栏；
    2. **新建子页面**：在当前节点下方唤出快捷内联创建输入框；
    3. **复制页面引用**：一键复制 `[[页面标题]]` 引用格式到系统剪贴板；
    4. **复制页面名称**：一键复制纯文本页面标题到系统剪贴板；
    5. **展开全部子项**：递归展开当前分支下的全部子节点；
    6. **折叠全部子项**：递归收起当前分支下的全部子节点；
    7. **重置当前层自订排序**：恢复当前层级的默认标题排序（仅在该层存在自定义排序时显示）。
- **5 级高可用剪贴板引擎**：
  - 彻底解决 Logseq iframe 运行沙箱中 Chromium `Document is not focused` 复制失败痛点；
  - 链路覆盖：Electron 原生剪贴板 API ➔ 宿主顶层异步剪贴板 ➔ 插件 iframe 异步剪贴板 ➔ 宿主 DOM 降级 ➔ iframe DOM 降级；
  - 复制成功提供 Toast 即时反馈，保证 100% 成功率。
- **100% 全自动新建子页面（原生 Page Tags 体系）**：
  - 支持在任意节点下快捷输入标题并创建子页面（按 Enter 提交，按 Esc 取消）；
  - **原生 DB Page Tags 自动绑定**：优先采用 Logseq DB 标准 `Page Tags`（在中文界面呈现为 `🗋 页面标签`），直接将父页面实体 ID（`[parentId]`）赋给新页面，并调用 `addBlockTag` 同步 Tag 实体；
  - **纯净页面创建**：移除多余的空白块插入，页面创建后干净纯粹，无任何多余的空圆点 `• `；
  - **双重校验与自动定位**：后台自动轮询校验 Datascript 索引与属性生效状态，自动展开父节点并将新子页面滚动至视口高亮呈现；
  - 重名智能拦截与错误安全保护。
- 上述操作在原生左侧边栏与悬浮面板模式下均完全可用。

## 3. 当前交互边界

- 层级关系只来自页面属性，不会修改 Logseq 原始数据结构
- 拖拽排序仅限同级节点内重排，不支持跨层级改父子关系
- 搜索状态下不允许拖拽排序
- 当前不提供从插件内直接"新增收藏"或"移出收藏"的操作

## 4. 建议补充的下一阶段功能

### 4.1 P0：高价值低风险

- 拖拽时增加更明显的落点提示与排序反馈

### 4.2 P1：提升日常使用频率

- 从当前页一键加入收藏
- 从节点快捷移出收藏

### 4.3 P2：增强复杂场景体验

- 搜索结果高亮路径
- 更细的异常提示与空状态说明
- 针对超大图谱（数万页）做虚拟滚动支持
